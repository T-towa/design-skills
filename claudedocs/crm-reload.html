Tsumugi CRM Reload

前回の統合案（一覧＝Garden＋kamii、詳細＝Lightning＋Serendie＋Atlassian、スレッド＝Slack、⌘K）の操作の流れはそのままに、見た目と動きをペルソナ 3 リロード／ペルソナ 4 リバイバルの UI の考え方で作り直した版です。

取り入れた考え方

  • 蒼（リロード風）：海のような青と「水・泡」のモチーフ。画面は上から「沈み込む」ように現れる。ホバーはシアンと赤の補色を左右にずらす。
  • 黄（リバイバル風）：黒地に黄色と青緑。明るさと「警告」を兼ねた黄色。画面はブラウン管が点くように開く。
  • 要素を減らし、優先度の低い情報は小さく区切る。主役（ビュー名・商談名・金額）は大きく斜めに置く。
  • メニューは斜めに並べ、選択中の項目を色の帯で強調する。数字は細長い斜体で大きく見せる。

業務 UI として守っていること

  • 文字色は背景に対して 4.5:1 以上。状態は色だけでなく文字（フェーズ名）でも示す。
  • 動きは OS の「視差効果を減らす」設定で止まる。飾りの動き（泡・光）は操作の邪魔をしない層に置く。
  • ゲームの画像・ロゴ・キャラクター・専用フォントは使っていません。色・構図・動きの考え方だけを参考にしています。
  • 参考：P3R 開発者インタビュー（UI） / AUTOMATON：P3R の UI デザイン / GamesRadar+：P4 Revival の UI
