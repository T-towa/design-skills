Tsumugi CRM Glass

比較で選んだ要素を 1 つの CRM にまとめ、Liquid Glass などの素材の仕様と、Slack・Linear の現代的な操作パターンを加えた統合案です。一覧の行を開くとクイックビュー、「タブで開く」で詳細ページになります。

一覧Garden のビューとタブ ＋ kamii の進み具合と「やること」 詳細Lightning のレコードページと Path ＋ Serendie の大きな金額 ＋ Atlassian のステータスとモーダル 配色Atlassian と Garden のコントラスト 素材Apple Liquid Glass ＋ Fluent 2 の Acrylic / Smoke 操作Slack のスレッド・リアクション・未読 ＋ Linear / Slack の ⌘K とショートカット

このモックで守っているルール

  • Appleガラスはナビゲーションと操作の層だけに使う（レール・上部バー・浮かぶ操作バー・⌘K）。表・フォーム・活動などのコンテンツは不透明にする。
  • Appleガラスの上にガラスを重ねない。ガラスの中のタブや入力欄は不透明の面にする。
  • Fluent 2一時的な面（クイックビュー・⌘K）は Acrylic 相当の厚いガラス、長く表示される土台は不透明（Solid / Mica の考え方）。
  • Fluent 2モーダルの背後は Smoke で暗くし、下の画面を操作できないことを示す。
  • Apple色付きのガラスは 1 か所だけ（ナビのレール＝Garden の Kale）。主要なボタンは不透明の主色で目立たせる。
  • Apple角丸は入れ子で同心円状にそろえる：外側 = 内側 + 余白（レール 24px = ボタン 14px + 余白 10px）。
  • Apple / FluentOS の「透明度を下げる」設定では自動で不透明に切り替える。下の切替でも確認できる。
  • Slack活動はスレッド形式：短い発言単位、@メンション、リアクション、返信数。未読の商談は太字と件数で示す。
  • Linear / Slack⌘K（Ctrl+K）でどこからでも商談や操作を呼び出す。主な操作にはショートカットを添える。
  • Atlassian文字は本文 #172B4D 相当の濃さを保ち、ガラスの不透明度は 56% 以上にしてコントラストを確保する。

ガラスのトークン（ライト）

--glass-bg: rgb(255 255 255 / .56);
--glass-strong: rgb(255 255 255 / .84); /* 一時的な面 */
--glass-sheen: rgb(255 255 255 / .38); /* 上部の反射 */
--glass-bd: rgb(255 255 255 / .72);
--glass-hi: inset 0 1px 0 rgb(255 255 255 / .9);
--glass-shadow: 0 10px 30px rgb(9 30 66 / .14);
--blur: 22px;  /* backdrop-filter: blur() saturate(170%) */
--rail-bg: rgb(3 54 61 / .80);  /* Kale の色付きガラス */
--smoke: rgb(9 30 66 / .34);
--radius: rail 24 / bar 20 / tab 12 / button 10

SVG の displacement を使った屈折表現は Chromium でしか動かないため採用していません（Safari / Firefox 非対応）。
